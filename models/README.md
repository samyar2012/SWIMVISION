# Tracking model

`object_tracking_vittrack_2023sep.onnx` is the pretrained ViTTrack model from
the [OpenCV Model Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/object_tracking_vittrack).
It is used through OpenCV's official `TrackerVit` single-object tracking API.
