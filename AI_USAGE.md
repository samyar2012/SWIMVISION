## Rules for this project

- AI-generated code is **not** presented as written entirely by the student.
- The student must understand and be able to explain every part of the submitted code.
- Computer-vision results are never invented by AI; every displayed metric comes from video processing, user input, or an explicit calculation in the code.

## AI / machine-learning models used inside the running application

- **Pretrained computer-vision models (no training done by us):**
  - **Ultralytics YOLO11** - detects people in frames (trained by Ultralytics on the COCO dataset).
  - **ByteTrack / BoT-SORT** (via Ultralytics) - links detections into tracks over time.
  - **OpenCV `TrackerVit`** (VitTrack ONNX model from the OpenCV Zoo) - follows a user-drawn box when YOLO cannot see the swimmer.
  - **SAM 2.1** (Segment Anything 2, Meta; run through Ultralytics) - the default tracker: segments the swimmer from the user's checkpoint boxes and follows them through the video. It is a general-purpose model, not trained on swimming.
  - Evaluated but **not adopted**: open-vocabulary **YOLO-World** (inconsistent on swimmers in water). Not part of the app.
  - Planned: **MediaPipe Pose** (Phase 3).
- **Phase 9 (planned, optional):** a text-generation API will turn already-calculated metrics into a plain-English explanation. It receives only numbers/text, never video, and is instructed not to invent measurements. The app works fully without it.
- No generative AI is used for the video analysis itself.

## Test data note

- Phase 1 tests use small synthetic videos generated by the test code (and FFmpeg's built-in test pattern) so frame rate, frame count and resolution have known true values.
- Phase 2 automated tests use a synthetic video with a moving patch of known position, so tracking error can be measured exactly.
- During Phase 2 development, two **public-domain** historical open-water swimming films from Wikimedia Commons ("2 KM ZWEMWEDSTRIJDEN" and "ZWEMWEDSTRIJDEN OM DE SCHELDEBEKER") were downloaded to a temporary folder **outside the project** and used for manual testing only. They are not committed to the repository. No accuracy figure is claimed from them; they are not modern pool footage.
